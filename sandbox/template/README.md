# Albie's sandbox

Albie (the Forge pet) edits this repo by voice, live in VS Code, so the real Forge repo stays untouched.
It was built by `sandbox/setup.sh` in gatorhack-dubz; `sandbox/setup.sh --reset` throws away Albie's edits.

| Folder | What it is | Try saying |
|---|---|---|
| `ml/` | The CIFAR-10 trainer the ML desk runs (`train.py`, `model.py`, `.forge/`) | "Albie, lower the learning rate and train again" |
| `cad/` | Every CAD part; the hub rebuilds the 3D model when one is saved | "Albie, make the rocket body 20% longer" |
| `bug/` | `flight_stats.py` has one planted bug; `pytest bug` shows it | "Albie, the flight stats test fails, fix it" |
| `web/` | A small launch page | "Albie, make the launch button orange" |
